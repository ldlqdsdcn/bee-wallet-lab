# Bee Wallet Lab 功能清单

对应版本 **v0.2.0**（含之后已合入仓库的三方连接、WalletConnect、代理与应用内浏览器改动）。

本地优先的多链实验桌面钱包。助记词和私钥只留在本机主进程，交易在本机签名后广播。

仓库：https://github.com/ldlqdsdcn/bee-wallet-lab  
最新安装包：https://github.com/ldlqdsdcn/bee-wallet-lab/releases/latest

发币步骤见 [发币说明.md](发币说明.md)。Linux 包校验见 [linux-signing.md](linux-signing.md)。

## 支持的链

| 链 | 能做什么 |
| --- | --- |
| **Bitcoin** | HD；Legacy / Nested SegWit / Native SegWit / Taproot；转账；跨链桥；BIP-137 签名 |
| **EVM** | 常见主网与 L2；ERC-20；兑换；跨链桥；发币；合约；交易实验室；批量转账 |
| **TRON** | HD；TRX / TRC-20；主网兑换；跨链桥；租能量或烧 TRX；合约 |
| **Solana** | HD；SOL / SPL；固定总量 SPL；消息签名 |

内置包括 Ethereum、BSC、Base、Optimism、Polygon、Arbitrum、Linea、Scroll、zkSync Era、Blast、Mantle、Avalanche、Xone 及对应测试网。可自己加网络。Sui 等未接入链不能用。

## 安全与钱包

- 主密码：scrypt + AES-256-GCM；空闲自动锁定；立即锁定；连续失败递增延迟
- 创建 / 导入：BIP-39（12–24 词），可选 Passphrase；导入助记词或私钥；多钱包切换
- 按当前网络派生账户；导出助记词 / 查看私钥需再输主密码
- 分层钱包：最多约 2 万条地址，私钥加密；列表可按序号范围查询，批量派生在弹框里做；可导出当前查询的 CSV 或逗号分隔地址文本
- 设置：改主密码、法币计价、目录站地址、界面语言（简体中文 / English）
- 目录站鉴权：首次启动生成本机专用 EVM 私钥（类似设备 ID，不进钱包列表、不跟主密码绑定）；启动时若 JWT 没有或过期则自动重签并保存

## 资产与转账

- 资产总览：直连 RPC 取余额，法币计价；节点不可达时用本地缓存
- 收款：地址 + 二维码；复制地址后按钮显示「已复制」，约 3 秒还原
- 转账：本机签名后广播；费率分档；TRC-20 能量不足时可租能量或烧 TRX。付款账户弹框选择：主账户在前，可选分层地址，显示所选币余额，可按地址模糊搜或按余额范围筛，每页 20 条
- 交易记录：按当前钱包 + 当前网络同步转入转出；EVM 广播后先显示待确认，等回执再标成功或失败
- 地址簿：本机保存公开地址。选用时按链类型（EVM / Solana / Bitcoin / TRON）筛选，不按具体网络 ID；比特币再区分主网和测试网

## 兑换与跨链

- **兑换**：同网络换币。ETH / BSC / Arbitrum（0x），波场主网（SunSwap）；必要时授权或租能量
- **跨链桥**：比特币、ETH / BSC / Arbitrum 与波场互跨；BTC 走 SwapKit，其余走 0x；源链本机签名

## 三方 DApp

- **应用内浏览器**：https 站点在钱包里开标签
- **目录站**：分类 + 热门站点（需在设置里填写目录站地址并登录）
- **手填网址**：自己输入 https DApp；没写协议时自动补 `https://`；只接受 https
- **EIP-6963**：站点自动发现 **Bee Wallet Lab**，并显示蜜蜂 logo
- **EIP-1193**：连接、切链、签名、发交易；账户或链没变时不重复广播，避免页面刷个不停
- **WalletConnect**：粘贴 `wc:` 或页面打开深链接会弹确认；会话列表、断开；网站断开后列表会跟上
- 连接前请自行核对网址，不要打开陌生链接

## 实验室与开发

- 交易实验室：构造、解码、只签名、再单独广播
- ABI 工具：导入 ABI；编码 calldata；解码调用、返回值、Event
- 合约交互：EVM / TRON 读 view、写合约；可只签名再广播
- 开发工具：JSON 格式化；Hex ↔ UTF-8 / Base64；SHA-256、Keccak-256
- 发行代币：EVM 固定总量 ERC-20；Solana 固定总量 SPL + Metaplex
- 批量转账：EVM 上打主币或 ERC-20，分两个入口。**同额批量**用地址列表（逗号文本、文件、地址簿），每人同一金额或随机区间。**明细批量**按行填写收款地址、名称、金额，可从地址簿带入地址和名称，也可上传 CSV（收款地址,名称,转账金额），表格可增删改。付款账户与转账页相同。进行中按钮显示「转账中」；两类历史分开保存，失败可单笔或批量重试
- 消息签名：EVM / TRON `personal_sign`；Bitcoin BIP-137；Solana Ed25519

## 网络与环境

- 网络 / 节点 / 代币维护；RPC 测速；自定义节点可填请求头（如 API Key）并可改 URL、备注和请求头
- 测试网水龙头（应用内打开）
- HTTP / SOCKS5 代理：多条、测速、选用；列表按添加顺序，点「使用」不会跳到第一行
- 系统通知（如交易确认）点开可进交易记录

## 桌面与发布

- 左侧导航：资产交易、钱包管理、应用连接、开发与发行、网络管理；分组可折叠，资产交易默认展开，设置固定在底部
- 顶部菜单沿用相同功能分类；复制 / 粘贴 / 全选归到「编辑」，应用分类收纳为子菜单；跳转页面时自动展开左侧对应分组
- Electron 桌面端：Linux AppImage / `.deb`（可选 GPG 校验）、Windows、macOS
- 打 `v*` tag 由 GitHub Actions 打包装到同一条 Release
- 不做 MetaMask 伪装（不设 `isMetaMask: true`）
- 密钥不进渲染进程、不进 git
- 无自动更新；菜单「检查更新」会说明从 GitHub 下载
- 无应用内站内信；Dock 未读角标来自系统通知
