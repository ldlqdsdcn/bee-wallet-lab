# 发行代币说明

Bee Wallet Lab 可以发行 **固定总量** 代币：

- **EVM**：部署 ERC-20 合约
- **Solana**：创建 SPL mint，并写入 Metaplex 名称 / 符号 / 元数据 URI（logo、官网写在这份 JSON 里）

全部代币在发行时一次性铸给发行账户，之后不能再增发。

入口：侧栏 **发行代币**，或菜单「工具 → 发行代币」。

## 能发什么

| 网络 | 类型 | 说明 |
| --- | --- | --- |
| Ethereum / Base / BSC / Sepolia 等 | ERC-20 | 内置 `BeeFixedERC20`，构造时铸完 |
| Solana 主网 / Devnet | SPL | 创建 mint → 铸给发行账户 → 关掉增发；名称、符号、元数据 URI 写入 Metaplex |
| Bitcoin / Tron | 不支持 | 请先切换网络 |

不是可增发、可销毁、有税、有黑名单的复杂代币。

## 发之前准备

1. 解锁钱包，侧栏选好 **钱包** 和 **网络**。
2. 当前钱包里要有对应链的账户（EVM 或 Solana，在「钱包与账户」派生或导入）。
3. 发行账户要有够付手续费的 **原生币**：
   - EVM：ETH / BNB 等（Gas）
   - Solana：SOL（签名费 + mint / ATA / 元数据租金，大约几厘 SOL）
4. 节点用你平时的 RPC 即可（例如付费 Infura；Solana 用目录里的节点）。

测试建议先走 Sepolia、Base Sepolia 或 Solana Devnet。主网部署不可撤销。

## 参数怎么填

| 字段 | 规则 | 说明 |
| --- | --- | --- |
| 发行账户 | 当前网络对应的地址 | 发行成功后，全部代币打到这个地址 |
| 代币名称 | EVM：1–64；Solana：1–32 | 例如 `Bee Token` |
| 代币符号 | EVM：1–16；Solana：1–10 位大写字母或数字 | 例如 `BEE`，界面会自动转大写 |
| 精度 | EVM：0–18（默认 18）；Solana：0–9（默认 9） | 总量按这个精度换算成最小单位 |
| 发行总量 | 必须大于 0 | 默认 `1000000000`（10 亿枚），也可选 1 亿 / 1000 万 |
| 简介 / Logo / 官网 | 仅 Solana，可选 | 写入链下 Metaplex JSON（`description` / `image` / `external_url`） |
| 元数据 URI | 仅 Solana，可选，最长 200 | 托管后的 JSON 地址。不填则链上只有名称符号 |

Solana 链上数量是 u64。精度 9、总量 10 亿没问题；精度再高、总量再大可能超出上限。

改参数后需要重新点预览。Solana 预览时就会生成 **Mint 地址**，以及一份可复制的元数据 JSON。

### Solana logo / 官网怎么上链

链上 Metaplex 账户只存 **name、symbol、uri**，不直接存图片。常见发币工具也是让你先准备一份 JSON：

```json
{
  "name": "Bee Token",
  "symbol": "BEE",
  "description": "…",
  "image": "https://…/logo.png",
  "external_url": "https://…"
}
```

本页会按你填的简介、Logo、官网生成这份 JSON。你把它传到可公开访问的 https / IPFS / Arweave 地址，再把链接填进「元数据 URI」（最长 200 个字符，这是 Metaplex 限制）。Phantom、Solscan 等会按这个 URI 拉 logo 和官网。

不填 URI 也能发行：链上仍有名称和符号；Logo 只会记在本机代币目录，别人钱包看不到。元数据账户设为可改（`is_mutable`），以后可以用同一份 mint 更新 URI；增发权限仍会关掉。

## 操作步骤

1. 打开 **发行代币**，确认顶部是目标网络。
2. 选发行账户，填名称、符号、精度、总量。Solana 还可填简介、Logo、官网，以及托管后的元数据 URI。
3. 点 **预览**。会看到接收地址和预估费用；Solana 还会看到 Mint 地址和待托管的 JSON。
4. 核对无误后点 **签名并部署**。
5. 先出现交易哈希，状态为待确认；确认后写入本地代币目录。
   - EVM：确认后出现 **合约地址**
   - Solana：Mint 地址在预览时已知，确认后即可在浏览器查看
6. 到 **资产总览** 刷新，就能看到发行账户的余额（等于发行总量）。

页面上方「已部署」列表按当前网络显示历史：名称、符号、总量、合约 / Mint 地址、交易哈希、状态。

## 发完之后

- 代币会加入本机目录（ERC-20 或 SPL），转账页能选到。
- EVM 上还可以用 **批量转账**：同额批量按地址列表打同一金额；明细批量按行填写地址、名称和金额。Solana 批量转账尚未接入。
- 点记录上的 **转账** 可直接去转账页。
- 合约 / Mint、交易可以在区块浏览器里打开。
- 链上不能再 mint。要更多数量只能再发一枚新币，或从已有持币地址转出来。

## 状态

| 状态 | 含义 |
| --- | --- |
| 待确认 | 已广播，还在等链上确认 |
| 已确认 | 发行成功，已写入本地目录 |
| 失败 | 交易失败 |

关掉窗口不影响。确认后仍会回写记录。

## 常见问题

**预览提示当前网络不支持**  
换成 EVM 网或 Solana。

**没有发行账户**  
到「钱包与账户」派生对应链的账户。

**费用不够**  
EVM 打入 Gas 币；Solana 打入 SOL。预览里的费用是估算，含新建账户租金。

**符号报错**  
只能用 A–Z、0–9，不要空格、中文、横杠。

**资产总览暂时看不到**  
等状态变成「已确认」，再刷新资产。也可在「代币维护」里确认合约 / mint 已在目录中。

**Solana 浏览器里名称是 Unknown / 没有 logo**  
名称符号来自链上 Metaplex；logo 和官网来自元数据 URI 指向的 JSON。没填 URI、URI 打不开、或节点拒了带元数据的交易时，浏览器只会显示 Unknown / 无图标。本应用在元数据交易被拒时会自动改成只建 mint（名称仍在本机目录里）。

**想改名称、总量**  
EVM 合约和已关掉增发的 SPL mint 改不了总量。Solana 若当时写了可改元数据，可以另发一笔更新 URI（本页暂不提供改元数据）。要改总量只能再发一枚新币，或从已有持币地址转出来。

**别人钱包里能看到吗**  
能。对方把合约地址或 Mint 加入钱包即可。本应用只在本机目录里自动登记。

## 安全说明

- 助记词和私钥只留在本机主进程。
- 主网发行前务必核对网络、账户、总量。发错网或发错量无法撤回。
- 这是实验钱包里的固定总量模板，未做审计背书，主网正式项目请自行评估。
